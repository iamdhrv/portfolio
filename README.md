# Dhruv's Portfolio 🌐

A retro-themed terminal portfolio with both **web** and **SSH** versions.

## ✨ Features

### 🎮 Retro Experience
- **BIOS Boot Sequence** - Realistic POST, memory test, hardware detection
- **CRT Scanlines** - Vintage monitor effect
- **Typewriter Text** - Boot messages type out character by character

### 💻 Commands
| Command | Description |
|---------|-------------|
| `help` | Show all available commands |
| `about` | About Dhruv |
| `projects` | Featured projects |
| `whoami` | ASCII portrait |
| `contact` | Get in touch |
| `music` | Retro Bollywood music player |
| `weather` | Current weather display |
| `matrix` | Enter the Matrix 🌐 |
| `guestbook` | Sign/view guestbook |
| `snake` | Snake game preview |
| `dvd` | DVD bounce animation |
| `fortune` | Fortune cookie |
| `sysinfo` | System information |
| `theme` | Change theme [minimal/matrix/ocean] |

### 🎨 Themes
- **minimal** - Clean, simple look
- **matrix** - Green Matrix-style
- **ocean** - Cyan ocean vibes

## 🚀 Running Locally

### Web Version
```bash
cd web
npm install
npm run dev
```
Open http://localhost:3000

### SSH Version (CLI)
```bash
cd cli
npm install
npm start
```
Then connect: `ssh localhost -p 2222`

## 🛠️ Tech Stack
- Next.js 14 (Web)
- React + TypeScript
- Node.js + ssh2 (CLI)
- Tailwind CSS
